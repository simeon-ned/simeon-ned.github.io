PSM

Predictive Style Matching for Natural Locomotion

Nedelchev et al. · 2026 preprint · Unitree G1 hardware

PSM — Key Idea

  • Offline predictor maps lower-body state + velocity commands → upper-body & gait targets
  • Style injected during RL training; task-only deployment at run time
  • Natural, robust humanoid locomotion on Unitree G1

LocoGen

Command-Conditioned Locomotion Generation

Ongoing · code not yet published

LocoGen — Approach

  • Combines learned motion matching + flow matching
  • Online, command-conditioned full-body locomotion (G1-first, robot-agnostic)
  • ~800 FPS (LMM) · ~150 FPS (flow) · Viser interactive control
  • Validated with BeyondMimic / ZEST in sim and on hardware

mink-warp

Batched Differential IK on MuJoCo Warp

mink-warp — Highlights

  • GPU-parallel task-space IK for many worlds at once
  • Mink-shaped API on MuJoCo Warp: frame tasks, COM, closed chains, hard limits via GPU ADMM
  • CUDA graph capture for real-time loops
  • Examples: Panda, UR5e, Cassie, dual iiwa, G1
