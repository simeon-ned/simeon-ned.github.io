Recent Projects

Humanoids, RL, sim-to-real — full portfolio at simeon-ned.github.io

WBC-Mjlab

Whole Body Control in MuJoCo Lab

One shared MDP for whole-body motion tracking in mjlab — train once on a motion library, deploy one policy for many skills. Multi-clip training, paper-specific task presets, and sim-to-real export.

Demo · Code · Docs

PSM

Predictive Style Matching for Natural Locomotion

Natural and robust humanoid locomotion via an offline predictor that maps lower-body state and velocity commands to upper-body and gait targets during RL training — task-only deployment on Unitree G1.

Nedelchev et al. · 2026 preprint

Project · Paper · Code

LocoGen

Command-Conditioned Locomotion Generation

Learned motion matching + flow matching for online, command-conditioned full-body locomotion on Unitree G1. Interactive Viser control with stand / walk / run transitions; validated with BeyondMimic / ZEST in sim and on hardware.

Ongoing · code not yet published

Sber Green Humanoid

RL Locomotion & Whole-Body Control · AIJ 2025

Core engineer on RL locomotion and WBC for the Green humanoid: improved naturalness of walking; WBC trained on synthetic reference trajectories without mocap; unified tracking for teleoperation, dance, and zero-shot skills.

Presentation

mink-warp

Batched Differential IK on MuJoCo Warp

GPU-parallel task-space IK with a Mink-shaped API on MuJoCo Warp — frame tasks, closed-chain equality constraints, and hard limits via GPU ADMM. CUDA graph capture for real-time loops; Panda, Cassie, G1 examples.
